# Justitia's playground 使用說明 v3.12.8

> 司律陪考資料庫｜攻克國考有如神助

司法官／律師第一試的刷題、正式模考、節奏診斷與間隔複習平台。題庫為考選部 105–114 年官方考古題，共 **40 卷、2,968 題**。

英文技術文件（安裝、部署、資料庫升級）：[`README.md`](./README.md)

## 開始之前

1. 進入首頁，點「開始刷題」。
2. 第一次使用會要求 Email 登入（Magic Link，不用設密碼）。信件裡的連結點開就完成登入。
3. 登入後才會保存答案、標記、筆記、計時與成績。未登入可以瀏覽，但不能開始作答。

## 一、選擇練習方式（開始練習）

### 依年度

- 每個年度是一個**收合區塊**，最新年度預設展開，其他點一下展開。
- 每張卡片顯示卷別、代號、題數、時長、滿分與涵蓋科目，並附官方試題連結。
- 按「開始這一卷」會依官方題序與官方時長建立一回模考。

### 依科目

三個步驟，手機上最下方會有一條**吸底的摘要列**，隨時看到年度、題數、預估時長與抽題方式，並直接按「建立自組模考」。

1. **複選年度** — 題目會從所選年度混合抽樣。
2. **快速選卷或自由選科** — 可套用預設組合，或自己點科目；民法可再選子科目（債總、物權…）。
3. **設定這回模考** — 自訂名稱、模考日期與出題數量。

> 出題數量若與預設題數不同，會啟用**近 10 回錯題優先**：先從最近 10 次有交集的作答中抽同範圍錯題，不足再從題池隨機補足。

## 二、作答頁

手機版以「看得到題目與選項」為第一優先，其他功能都收在收合區或吸底列，功能一個都沒少。

| 位置 | 內容 |
| --- | --- |
| 最上方 | 卷名與計時器（吸頂，高度已壓到最小） |
| 左上角膠囊 | **題號索引**，預設收合。點開看整張答題卡，已作答、目前題、已標星號都有標示；點題號直接跳題並自動收合 |
| 中間 | 題目與選項 |
| 吸底換題列 | **星號**、上一題、下一題（最後一題變成「交卷」） |
| 換題列下方 | **作答輔助**收合區：信心程度（確定／不確定／純猜）與筆記 |
| 頁面最底 | 離開、提前交卷 |

要點：

- **星號**在換題列上，捲到哪都能標。標過的題目在題號索引上會出現 ★。
- **信心程度**要先選答案才能點；改答案會清掉原本的信心紀錄。
- 答案是**即時保存**的，右上角會顯示「保存中／已保存」。網路異常時 10 秒內會提示保存逾時，此時仍然可以交卷。
- 計時卷時間到會**自動交卷**。切到背景分頁不計入單題有效時間，但倒數不會暫停。
- 電腦版排版不變：題號索引固定在左側側欄，信心與筆記常駐顯示。

## 三、檢討（作答紀錄頁）

交卷後進入檢討頁，這是提升分數最重要的一頁。

- **成績摘要**：總分、百分比、滿分題／未滿分／未作答、總花費時間。
- **時間與資料來源**（收合）：模考日期、開始與交卷時間、時長設定、官方答案連結。
- **答題節奏診斷**（收合）：各科平均秒數、最耗時題目、前後半卷、最後十分鐘、改答案效果、信心校準。
- **錯題分布**：各科與子科目的未滿分與未答統計。
- **篩選頁籤**：全部／未滿分／未作答／滿分／模考星號／檢討星號。手機上是單行左右滑動。
- **右下角浮動按鈕「下一個未滿分」**：直接跳到下一題沒拿滿分的題目，檢討時不用自己捲。

每一題的卡片：

- **滿分題預設收合**，只留一行摘要（得分、花費時間），要看題目再點「展開題目與選項」。
- 未滿分題預設完整展開，顯示題幹、所有選項（標出你的選擇與官方答案涉及的選項）、答案比較（你的答案、可接受答案、得分、花費時間、信心、改答案次數）。
- **這題為什麼沒拿滿分**（收合）：標主要錯因與補充標籤，會累積到學習診斷。
- **第三方外部參考**（收合）：110–113 年部分題目提供外部詳解連結，只提供連結、不重製內容。
- **加入檢討標記**：跨回合保留，之後可以用來組複習卷。
- **其他標記與筆記**（收合）：左邊是當時的模考筆記（唯讀），右邊可編輯檢討筆記。

## 四、今日待複習

系統依得分與信心自動安排 1／3／7／14／30 天後再次出題。答錯會回到 1 天；連續兩次「確定且答對」會延長到 30 天。

- 上方三格：今天到期、尚未到期、下一批日期。
- **科目分布**（預設展開）：今天到期的題目分布在哪些科目。
- **學習診斷**（收合）：最近五回的常見錯因、高風險錯誤認知（確定但錯、純猜但錯）、尚未穩定掌握。
- 下方選 10／20／30／全部，按「開始複習」建立**不計時**組卷。優先順序：答錯 → 猜對 → 不確定答對 → 其他到期題。

---

## 五、歷史紀錄

- **篩選與排序**（收合）：方式、年度、卷種、模考日期起迄、最低／最高得分率、排序。收合後仍以 chip 顯示目前條件，可一鍵清除。
- **複習組卷**（收合，勾選回合後自動展開）：勾要當來源的回合，選擇條件（錯題／模考星號／檢討星號，取聯集，重複題只出現一次），按「建立複習組卷」。
- 每筆紀錄可「查看作答紀錄」或**永久刪除**。刪除會二次確認，並一併刪掉該回的答案、時間、模考星號與筆記、錯因；跨回合的檢討星號與筆記會保留，受影響題目的複習排程會重算。

## 兩種標記的差別

| | 模考星號／筆記 | 檢討星號／筆記 |
| --- | --- | --- |
| 綁定 | 單一作答回合 | 題目本身，跨回合 |
| 何時能改 | 作答中 | 檢討時，隨時 |
| 交卷後 | 鎖定不可改 | 可持續累積 |
| 刪除回合時 | 一起刪除 | 保留 |
| 用途 | 保留作答當下的判斷脈絡 | 長期考點整理、組複習卷 |

## 常見問題

**Q：手機上找不到某個功能？**
沒有任何功能被移除。作答頁的功能在「題號索引」膠囊與「作答輔助」收合區裡；檢討頁與歷史紀錄的功能在各個收合區塊裡。點一下標題列就會展開。

**Q：作答中可以離開嗎？**
可以。答案是即時保存的，從歷史紀錄點「繼續作答」回來。計時卷的倒數不會因為離開而暫停。

**Q：複選題怎麼計分？**
105–106 年的 A–E 複選題依官方規則計算部分得分，檢討頁會顯示「部分得分」。

**Q：官方答案會不會提前看到？**
不會。官方答案存在資料庫的 private schema，交卷前公開 API 不會回傳。
