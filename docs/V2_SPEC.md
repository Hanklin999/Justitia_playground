# V2 功能規格摘要

## 首頁

1. 依年度：年份 → 正式試卷 → 開始正式計時測驗。
2. 依科目：複選年份 → 選科目或快速組卷 → 從題池抽題。

## 科目題數與計時

- 科目題數取正式單一年度該科題數。
- 多年度只擴大 pool，不會把題數乘上年度數。
- 多科相加各科正式題數。
- 計時以各科所屬正式卷的每題平均秒數加總。
- 錯題重刷不計時。

## 刷題

- 單選答案
- 上一題／下一題／題號跳轉
- 已答、未答、星號狀態
- 私人筆記
- 每題頁面活躍秒數
- 答案與筆記自動保存

## 結果

- 開始時間、交卷時間、總花費時間
- 答對、答錯、未作答
- 各科與子科目分布
- 每題約略活躍秒數
- 星號與筆記
- 同年度四卷完成後的總分與歷史門檻

## 歷史

- 依年度、模式、科目與結果（有錯題／全對／作答中）篩選
- 顯示正式卷、自組卷、錯題重刷
- 依篩選條件重新建立不計時錯題卷

## 答案版本與複數有效答案

- 答案表保存原始答案、主要顯示答案與所有有效答案。
- 計分以 `accepted_answers` 判斷，不只比對單一答案。
- 已知例外：111 年公法卷第 50 題，A 或 B 均給分。
- 更正公告網址保存在 `official_notice_url`。
