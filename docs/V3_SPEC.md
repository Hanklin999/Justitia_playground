# Justitia's playground v3.0.0

## Release scope

- 題庫範圍：民國 105–114 年，共 40 卷、2,968 題。
- 105–106 年支援 A–E 複選題、每題 3 分、部分得分與官方更正／送分。
- 107–114 年支援單選題與官方更正答案。
- 年度模式：保留官方題序、題數、配分與考試時間。
- 科目模式：複選年度與科目，自動由題池抽取目標題數；時間按來源試卷平均每題秒數計算。
- 作答頁：題幹字級降低、選項字級提高；支援星號、筆記、自動保存與每題活躍時間。
- 結果／歷史：完整顯示題幹、A–E 選項、使用者選擇、可接受答案、單題得分與筆記。
- 年度四卷完成後：顯示總分，並比較 105–114 年司法官與律師第一試門檻。
- 錯題重刷：依年度／科目篩選，建立不計時練習。

## Old-format question mapping

105–106 年科目位置依使用者提供的題號規則：

- 刑事法：刑法單選 1–26、複選 61–66；刑訴單選 27–45、複選 67–70；法律倫理 46–60。
- 公法：憲法單選 1–14、複選 61–64；行政法單選 15–40、複選 65–70；國際公法 41–50；國際私法 51–60。
- 民事法：105 與 106 年財產法／親屬繼承依各年度不同題號切分；民訴單選 39–62、複選 71–74。
- 商事法：公司法 1–15、保險法 16–25、票據法 26–35、證交法 36–45、強執法 46–55、法學英文 56–70。

## Scoring

- 單選：選中任一官方可接受答案即得該題滿分。
- 複選：與任一官方可接受組合完全一致得滿分；差一個選項得 60%；差兩個選項得 20%；其餘 0 分。
- 送分題：無論有無作答均給該題滿分。
