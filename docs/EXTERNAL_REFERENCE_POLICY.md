# 第三方外部詳解呈現規範

## 網站可做

- 僅放一般超連結，讓使用者自行前往原發布頁。
- 顯示「第三方外部參考」與「來源：全人法學中心」。
- 顯示連結涵蓋的題號範圍，提醒使用者自行找到當前題號。
- 使用 `target="_blank"`、`rel="noopener noreferrer"`、`referrerPolicy="no-referrer"`。
- 以 Supabase metadata 管理 URL、驗證時間與狀態。

## 網站不做

- 不嵌入 Facebook 圖片、貼文或縮圖。
- 不下載、重傳、裁切、截圖或移除品牌／水印。
- 不 OCR、摘要、改寫或以 AI 產生對方內容的替代詳解。
- 不使用「合作詳解」「官方推薦」等可能暗示授權或合作的文字。
- 不以程式抓取貼文內容。
