# Justitia_playground｜V2 產品決策

- 品牌：**Justitia's playground**
- 副標題：**司律陪考資料庫**
- 視覺：簡約、藍白、手機優先
- 題庫：民國 110–114 年，共 20 份綜合法學試卷、1,500 題
- 題目來源：考選部官方考古題與標準答案 PDF
- 第一階段不提供題目詳解
- 登入：Email Magic Link

## 作答模式

### 依年度

年份 → 正式試卷 → 使用官方題數與官方時長。單卷做完立即顯示成績；同年度四卷完成後顯示總分與歷史錄取／及格門檻。

### 依科目

複選年份與科目，從符合條件的題池抽取該科正式題數。計時依原正式卷每題平均秒數等比例計算，並標示為「自組測驗」，不宣稱是全真正式模擬。

提供四個組卷捷徑：

- 公法卷：憲法、行政法、國際公法、國際私法
- 民事法卷：民法、民事訴訟法
- 商事法卷：公司法、保險法、票據法、證券交易法、強制執行法、法學英文
- 刑事法卷：刑法、刑事訴訟法、法律倫理

錯題重刷不計時。

## 作答紀錄

- 每一次 attempt 都保存開始、截止、交卷、實際花費時間與交卷原因。
- 題目答案、星號、私人筆記與題目活躍秒數分開保存。
- 星號代表「不會／需要回頭」，不等於答錯。
- 收藏／標記與系統判定錯題分開。

## 分數比較

- 司法官與律師門檻分開保存。
- 歷史門檻只做當年度回顧比較，不是當年度錄取預測。
- 四張正式卷均完成後才形成年度總分。

## 官方答案更正

- 不能假設每題永遠只有一個有效答案。
- private answer key 保存 `original_answer`、`final_answer`、`accepted_answers` 與官方公告網址。
- 111 年公法卷第 50 題接受 A／B，兩者都計分。
