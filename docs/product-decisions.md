# Justitia's playground｜v3.0.0 產品決策

- 品牌：**Justitia's playground**
- 副標題：**司律陪考資料庫**
- 視覺：簡約、藍白、手機優先
- 題庫：民國 105–114 年，共 40 卷、2,968 題
- 題目來源：考選部官方考古題與標準答案 PDF
- 第一階段不提供題目詳解
- 登入：Email Magic Link

## 作答模式

### 依年度

年份 → 正式試卷 → 使用該年度官方題序、題數、配分與時長。單卷做完立即顯示成績；同年度四卷完成後顯示 600 分總分與該年度司法官／律師歷史門檻。

### 依科目

複選年份與科目，從符合條件的題池抽取目標題數。時間依來源正式卷平均每題秒數等比例計算，並標示為「自組測驗」，不宣稱為全真模擬。

提供四組快速組卷：

- 公法卷：憲法、行政法、國際公法、國際私法
- 民事法卷：民法、民事訴訟法
- 商事法卷：公司法、保險法、票據法、證券交易法、強制執行法、法學英文
- 刑事法卷：刑法、刑事訴訟法、法律倫理

錯題重刷固定不計時。

## 舊制複選題

105–106 年保留 A–E 選項及複選作答：

- 完全符合任一官方可接受組合：100% 題分
- 差一個選項判斷：60% 題分
- 差兩個選項判斷：20% 題分
- 其他：0 分
- 送分題：直接給滿分

## 作答紀錄

- Attempt 保存開始、截止、交卷、實際花費時間與交卷原因。
- 每題保存答案、星號、私人筆記與活躍秒數。
- 星號代表「不會／需要回頭」，不等於系統判定答錯。
- 使用者答案與系統錯題判定分開保存。

## 歷史回看

已交卷紀錄必須能重新顯示：

- 完整題幹
- A–E 全部可用選項
- 使用者當時選擇
- 官方可接受答案
- 單題得分／滿分
- 星號、筆記、活躍時間

## 分數比較

- 司法官與律師門檻分開保存。
- 歷史門檻只做當年度回顧比較，不是未來錄取預測。
- 同年度四張正式卷均完成後才形成年度總分。

## 答案安全

- 公開 `questions` 表不含答案。
- 答案存於 `private.question_answer_keys`。
- 計分、逾時、題目 payload 與結果 payload 透過 security-definer RPC 控制。
