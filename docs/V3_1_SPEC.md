# Justitia's playground v3.1.0 功能規格

## 標記生命週期

| 使用情境 | 星號／筆記類型 | 是否綁定回合 | 交卷後 |
|---|---|---:|---|
| 年度正式卷、科目自組模考進行中 | 模考標記 | 是 | 鎖定、唯讀 |
| 不計時複習組卷進行中 | 檢討標記 | 否 | 持續保留 |
| 結果／歷史作答紀錄 | 檢討標記 | 否 | 可編輯 |

## 歷史紀錄

- 一筆卡片代表一個作答回合。
- 篩選：方式、年度、卷種、模考日期起迄、最低／最高得分率。
- 排序：日期新舊、得分率高低。
- 查看完整選項、使用者答案與官方答案前需確認警告視窗。

## 複習組卷

- 使用者可勾選一回或多回已完成紀錄。
- 題目條件支援：錯題、模考星號、檢討星號。
- 多條件採聯集，同一題只出現一次。
- 不計時；作答期間更新檢討標記。

## 科目自組模考

- 可自訂名稱與模考日期。
- 題數預設為目前 scope 的標準配置。
- 時間按原卷平均每題秒數 × 實際抽題數計算。
- 題數與預設不同時：
  1. 找出使用者最近 10 次與本次 scope 有交集的已完成作答回合。
  2. 從這 10 回中，隨機抽取落在本次 scope 的答錯題；若錯題數足夠，可優先填滿指定題數。
  3. 剩餘題數從 scope 內排除已選題後不重複隨機抽取。
  4. 若指定題數超過題池，縮減到可用題數。
